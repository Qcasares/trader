# Runtime dependencies — the deployable set.
#
# This is the root `requirements.txt` on purpose: Vercel's Python runtime
# installs it by that name from the project root. Docker and CI use it too, so
# there is exactly one answer to "what does this application need to run".
# Development tooling lives in requirements-dev.txt.
#
# Deliberately excludes the legacy crypto agents' torch/transformers/nltk
# stack (~2.5GB), which is what makes this deployable at all. Installed, this
# comes to roughly 190MB — inside Vercel's 250MB unzipped function limit, with
# pandas and numpy accounting for over half of it.
#
# Every entry is permissively licensed (Apache-2.0/BSD/MIT). backtesting.py
# (AGPL-3.0), backtrader (GPL-3.0) and vectorbt (Commons Clause, which forbids
# selling a hosted service) were evaluated and rejected.
