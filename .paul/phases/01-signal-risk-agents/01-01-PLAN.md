## AC-1: Weighted Fusion Score Calculation
```gherkin
Given ticker_sentiments from SentimentAgent and technical_signals from TechnicalAgent
When SignalAgent.execute() processes the data
Then a combined_score is computed as: sentiment_score * 0.40 + technical_score * 0.40 + volume_signal * 0.20
And the score is clamped to [-1.0, +1.0]
```

## AC-2: Confidence Gating
```gherkin
Given a combined trade signal with confidence below min_confidence (0.55)
When SignalAgent evaluates the signal
Then the signal action is set to "hold" regardless of directional score
And the reason includes "below confidence threshold"
```

## AC-3: Multi-Factor Confluence Requirement
```gherkin
Given upstream data for a ticker
When fewer than 2 signal domains (sentiment, technical, volume) confirm the same direction
Then the signal action is set to "hold"
And the reason includes "insufficient confluence"
```

## AC-4: Claude Sonnet Reasoning
```gherkin
Given computed fusion scores for all watched tickers
When SignalAgent calls Claude Sonnet
Then the model receives a structured prompt with all indicator values
And returns a JSON response with action, confidence, and rationale per ticker
```

## AC-5: Anomaly Ticker Handling
```gherkin
Given a ticker flagged as anomaly by SentimentAgent (anomaly_detected=True)
When SignalAgent processes that ticker
Then the sentiment weight for that ticker is reduced to 0.10 (from 0.40)
And the remaining weight is redistributed to technical (0.55) and volume (0.35)
```

  <files>src/agents/signal.py</files>
  <action>
    Create src/agents/signal.py implementing SignalAgent that extends BaseAgent.

    **Data structures (dataclasses):**
    - `TradeSignal`: ticker, action ("buy"/"sell"/"hold"), combined_score (-1.0 to 1.0), confidence (0.0 to 1.0), sentiment_score, technical_score, volume_signal, rationale (str), anomaly_adjusted (bool)

    **Constructor:**
    - `__init__(self, api_key: str)` → call super with AgentRole.SIGNAL, model "claude-sonnet-4-6", api_key
    - Store AsyncAnthropic client for Claude calls

    **system_prompt():**
    - Return prompt defining agent as a quantitative trading signal analyst
    - Instruct it to evaluate multi-factor data and output JSON with action, confidence, rationale per ticker

    **execute(context: dict) → AgentResult:**
    1. Extract `ticker_sentiments` (list of TickerSentiment) from context
    2. Extract `technical_signals` (list of TechnicalSignal) from context
    3. Extract `anomaly_tickers` (set of str) from context (default empty set)
    4. Extract config values: min_confidence (default 0.55), weights
    5. For each ticker present in BOTH sentiment and technical data:
       a. Map sentiment composite_score (-1 to +1) to sentiment_score
       b. Map technical direction+strength to technical_score: bullish=+strength, bearish=-strength, neutral=0
       c. Map volume_surge (bool) + volume_ratio to volume_signal: if surge, +0.5 * min(volume_ratio/3, 1.0); else 0
       d. If ticker in anomaly_tickers: use weights (0.10, 0.55, 0.35); else standard (0.40, 0.40, 0.20)
       e. Compute combined_score = sentiment_weight*sentiment_score + technical_weight*technical_score + volume_weight*volume_signal
       f. Clamp to [-1.0, +1.0]
    6. Check confluence: count confirming domains (sentiment direction matches, technical direction matches, volume confirms)
       - If < 2 confirming domains → action = "hold", reason = "insufficient confluence"
    7. Build prompt with all ticker scores and call Claude Sonnet for final reasoning
       - Parse JSON response: action, confidence, rationale per ticker
       - If Claude's confidence < min_confidence → override action to "hold"
    8. Build list of TradeSignal dataclasses
    9. Return self._build_result(success=True, data={"trade_signals": [...], "signal_count": N})

    **Error handling:**
    - If context missing ticker_sentiments or technical_signals → return empty signals with warning
    - If Claude API call fails → fall back to rule-based scoring (use combined_score > 0.3 → "buy", < -0.3 → "sell", else "hold") with confidence = 0.5
    - Log all steps via self._logger

    **Do NOT:**
    - Import or depend on database modules (agents communicate via context dict)
    - Add any execution or bankr.bot logic
    - Create separate utility files — keep all logic in signal.py
