  <files>src/orchestrator.py</files>
  <action>
    Create `src/orchestrator.py` with the AgentOrchestrator class.

    **Constructor (`__init__`):**
    - Takes: config dict (from bot_config.yaml), api_keys dict, db_pool (DatabasePool), dry_run (bool)
    - Initializes all 7 agents using constructor signatures from context
    - Stores agent cadence schedule: main pipeline every loop_interval, portfolio every 2x
    - Tracks cycle_count, agent_heartbeat_status dict, running flag

    **Pipeline method (`run_cycle`):**
    - Build shared context dict with current_prices (from Research or empty), portfolio state
    - Execute agents sequentially in order:
      1. Research → adds research_data, current_prices to context
      2. Sentiment → adds sentiment_scores to context
      3. Technical → adds technical_signals to context
      4. Signal → adds trade_signals to context
      5. Risk → adds risk_decisions to context
      6. Execution → adds trade_results to context
    - Each agent wrapped in try/except — on failure, log error and add empty data to context
    - After each agent: call _record_heartbeat() to upsert_agent_heartbeat
    - Return cycle summary dict with per-agent success/failure and timing

    **Portfolio method (`run_portfolio_cycle`):**
    - Called every 2nd main cycle (30 min if main is 15 min)
    - Passes context with current_prices from latest cycle
    - Same try/except + heartbeat pattern

    **Heartbeat helper (`_record_heartbeat`):**
    - Wraps upsert_agent_heartbeat in try/except (non-fatal)
    - Tracks cycles_completed per agent, last_error if any

    **Main loop (`run`):**
    - Async method that runs indefinitely until self._running is False
    - Each iteration: run_cycle(), conditionally run_portfolio_cycle()
    - Sleep for loop_interval between cycles
    - Log cycle number, duration, number of successful agents

    **Shutdown (`shutdown`):**
    - Sets self._running = False
    - Logs shutdown message

    Avoid: Making agents call each other directly. All data flows through the context dict.
    Avoid: Fatal errors — every external call (DB, agent) must be wrapped in try/except.
