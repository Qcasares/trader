<objective>
## Goal
Create a PostgreSQL database layer with schema mirroring all 7 agent data structures and an async connection manager with repository functions for CRUD operations.

## Purpose
Agents currently communicate only via the orchestrator's context dict, which is ephemeral. A persistent PostgreSQL layer enables portfolio tracking, trade history, P&L calculation, agent health monitoring, and post-mortem analysis — all required for Phase 3 Plan 02 (PortfolioAgent) and Phase 4 (Orchestrator).

## Output
- `src/db/schema.sql` — 9-table PostgreSQL DDL
- `src/db/connection.py` — async connection pool manager via asyncpg
- `src/db/repositories.py` — typed async CRUD functions for all tables
- `src/db/__init__.py` — package exports
- Updated `requirements.txt` with asyncpg dependency
</objective>

       **Query functions** (each takes DatabasePool, returns list[dict] or dict):
       - `get_recent_trades(pool, ticker, limit=10) -> list[dict]`
         (FROM trade_results WHERE ticker=$1 ORDER BY executed_at DESC LIMIT $2)
       - `get_daily_pnl(pool) -> float`
         (SUM of amount_usd for successful trades today, accounting for buy=-/sell=+)
       - `get_portfolio_positions(pool) -> dict`
         (Latest portfolio_snapshot's positions JSONB)
       - `get_latest_portfolio_snapshot(pool) -> Optional[dict]`
         (Most recent snapshot)
       - `get_agent_heartbeat(pool, agent_role) -> Optional[dict]`
         (WHERE agent_role=$1)
       - `get_recent_signals(pool, ticker, limit=10) -> list[dict]`
         (FROM trade_signals WHERE ticker=$1 ORDER BY created_at DESC)
       - `get_trade_history(pool, since_hours=24) -> list[dict]`
         (JOIN trade_results + risk_decisions for last N hours)

       Each query function converts asyncpg Record objects to plain dicts.
       Use `dict(row)` for Record → dict conversion.

       All functions use parameterised queries ($1, $2, etc.) — never string formatting.
