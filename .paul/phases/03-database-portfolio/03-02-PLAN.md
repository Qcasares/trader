## Goal
Create PortfolioAgent — the final agent in the trading pipeline — that tracks positions, calculates P&L, detects drawdowns, and uses Claude Sonnet for portfolio analysis.

## Purpose
Without portfolio tracking, the bot has no visibility into overall performance, cannot detect drawdowns, and cannot adjust strategy. The PortfolioAgent closes the feedback loop by aggregating trade results into actionable portfolio metrics.

<task type="auto">
  <name>Task 1: Create PortfolioAgent with P&L tracking, drawdown detection, and Claude analysis</name>
  <files>src/agents/portfolio.py</files>
  <action>
    Create PortfolioAgent extending BaseAgent following the RiskAgent pattern:

    **Constructor:**
    - Takes api_key (str) and db_pool (DatabasePool)
    - Role: AgentRole.PORTFOLIO, Model: "claude-sonnet-4-6"
    - Store AsyncAnthropic client and DatabasePool reference

    **system_prompt():**
    - Define Claude as a portfolio analyst for a crypto trading bot
    - Instruct it to analyse position concentration, P&L trends, drawdown risk
    - Return JSON with analysis, risk_level ("low"/"medium"/"high"), recommendations

    **execute(context):**
    context receives: current_prices (dict ticker→price), portfolio_total_usd (float)

    Steps:
    1. Query DB for daily P&L via get_daily_pnl(db_pool)
    2. Query DB for current positions via get_portfolio_positions(db_pool)
    3. Query DB for previous snapshot via get_latest_portfolio_snapshot(db_pool)
    4. Query DB for recent trade history via get_trade_history(db_pool, since_hours=24)
    5. Compute portfolio metrics:
       - total_value_usd from context or sum of position values
       - Update positions with current prices from context
       - cumulative_pnl_usd = previous cumulative + daily delta
       - max_drawdown_pct = max of (previous drawdown, current drawdown from peak)
    6. Call Claude Sonnet with portfolio metrics for qualitative analysis
       - On failure: generate rule-based summary string (no crash)
    7. Save snapshot via insert_portfolio_snapshot(db_pool, snapshot_data)
    8. Return AgentResult with snapshot data, analysis, metrics

    **Helper methods:**
    - _compute_drawdown(current_value, peak_value, previous_max_drawdown) → float
    - _update_positions_with_prices(positions, current_prices) → dict
    - _build_rule_based_summary(metrics) → str — fallback when Claude unavailable
    - _analyse_with_claude(metrics, trade_history) → tuple[str, int, Optional[str]]

    **Key patterns to follow (from RiskAgent):**
    - time.monotonic() for duration measurement
    - Collect errors list, append Claude failures
    - _build_result() helper for standardised AgentResult
    - json module for Claude prompt construction
    - re.search for JSON extraction from Claude response
    - Safe defaults: empty positions, zero P&L, zero drawdown

    **Avoid:**
    - Do NOT import or call other agents directly — use database and context only
    - Do NOT use sqlite — this agent uses DatabasePool (asyncpg)
    - Do NOT skip the Claude fallback — graceful degradation is required
